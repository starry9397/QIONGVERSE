# Source Register

The executable source registry is `knowledge/source-registry.json`; the minimum approved content statements live in `knowledge/content-fact-ledger.json`. This document states their publishing rules.

| Source class | May support | Must not support |
| --- | --- | --- |
| Supplied project media | Curatorial visual context and asset captions | External factual, official, policy, travel, or commercial claims |
| Reviewed primary source | Only the record's stated scope and review date | Broader personal eligibility, endorsement, price, or outcome claims |
| ShellSong fiction | Clearly labeled narrative and Luoyin persona | Documentary, cultural, official, or historical claims |
| AI suggestion | Clearly marked explanatory or planning language | A citation, legal/policy conclusion, price, availability, or promise |

Every reviewed record requires publisher, canonical HTTPS URL, bilingual project-authored title, checked date, topic tags, permitted use, scope, limitation, and status. Source text is not mirrored wholesale. A failed source link leaves the source caption visible and tells the visitor to retry the original publisher.

Content pages may display only `reviewed` ledger records as external facts. `project_content` records may describe the project's own curatorial surface but cannot be expanded into tourism, policy, heritage, technical, or commercial assertions.

## Hainan regional map

`src/hainan-map-data.ts` contains the static city/county-level map controls and the public portal linked by each reading card. The umbrella record `hainan-regional-reading-map-source-register` keeps the map’s boundary visible in the verified source desk. These links provide public orientation only; they do not make the project-authored SVG an authoritative administrative map or establish access, transport, tickets, opening arrangements, safety, availability, or travel advice.
