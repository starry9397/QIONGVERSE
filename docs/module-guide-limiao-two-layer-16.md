# Module Guide: Li & Miao Two-Layer Visit / 黎苗两层参观路径

## 1. Module goal

- Make \`#limiao-hall\` open directly into the immersive Li & Miao world.
- Move Pattern Field, Weaving Reading Room, Hall View and concept-object navigation into a second, calm exhibit-index view inside the same route.
- Preserve the world as the first visual statement: SPZ scene, sparse world anchors, Luoyin, hand controls and return action.
- Help foreign visitors understand the path as: immersive world -> open exhibit index -> choose image/video/3D concept -> bilingual reading sheet -> return to world.

## 2. Content boundaries

- The first view must not become a dense gallery grid or card wall.
- The second view may use a restrained editorial list/grid for the six supplied exhibits.
- Li textile facts stay source-bound to UNESCO. Miao material stays project-supplied curatorial context.
- Models remain labelled AIGC concept exhibits; no historic-object, retail, price, stock, partnership or official claims.
- No new route, API, camera upload, persistence, identity tracking or commercial workflow.

## 3. Interaction and layout

- World view: one clear \`Open exhibit index / 打开展项索引\` control; world anchors remain visible but sparse and clickable.
- Index view: six exhibit entries with thumbnail, type, bilingual title, source label and open action; keyboard and touch reachable.
- \`Back to immersive world / 返回沉浸大世界\` returns to the same route without changing the main site.
- Detail sheets continue to support Escape, backdrop click, image/video fallback and GLB fallback.
- Model preview keeps wheel/pointer transforms and optional hand pinch scale plus horizontal rotation.

## 4. Visual system

- World remains dark teal, full-bleed and spacious.
- Index view uses Shell Paper with a single editorial grid and gold/coral rules; no nested cards, fake metrics or purple gradients.
- Mobile index becomes one-column reading list; 320px has no horizontal overflow.

## 5. Acceptance

- Entering \`#limiao-hall\` shows the immersive world first, not the index.
- The world has a visible path to the second view and the second view has a visible path back.
- Images, videos and all three models are reachable from the second view and from world anchors.
- Detail sheets still show bilingual text, source status and model gesture hint.
- Gesture permission remains opt-in; denial leaves ordinary controls intact.
- Build, server test, syntax, asset, secret, storage and responsive scans pass.

## 6. Next action

After acceptance, optimize Luoyin's exhibit-context prompt and citation display. Pause before adding persistence or external commerce.
