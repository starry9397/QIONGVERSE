# 模块引导：螺音云朵导览、服务端音色与俏皮语气

## 目标

将螺音桌宠升级为全站可用的轻量导览入口：聊天面板始终留在当前视口安全区，采用透明云朵视觉；语音只使用服务端注入的合成音色；离线与 GLM 回答保持海南省项目语境、来源边界和七语一致。

## 约束

- 螺音是 HAINAN∞QIONGVERSE 的原创虚构数字导览员，不代表真人、儿童、官方机构或商业服务人员。
- 不把聊天、位置、声音、账号或用户画像写入浏览器存储、日志或数据库。
- `GLM_API_KEY`、`LUOYIN_TTS_API_URL`、`LUOYIN_TTS_API_KEY`、`LUOYIN_TTS_VOICE_ID` 只存在服务端环境变量，不进入客户端或构建产物。
- TTS 未配置、超时或失败时返回 `unavailable`，保留文字回答，不调用浏览器 `speechSynthesis`，不伪造播放成功。
- 支持 `en / zh / id / ja / ko / ru / ar`。阿拉伯语保持 RTL；媒体、模型与地图坐标保持合理的 LTR 展示。
- 政策、签证、税务、投资、价格、库存、订单、开放状态与安全问题必须克制，并引导用户核验已登记的官方来源。

## 交互与无障碍

- 桌宠使用 Pointer Events 长按拖动；聊天面板根据左右和上下空间自动选择展开方向，并限制在 `16px` 安全边距内。
- 移动端聊天面板固定在底部安全区，宽度不超过视口；`Escape` 收起聊天并把焦点返回桌宠，关闭按钮提供双语无障碍名称。
- 云朵气泡只承载当前身份、状态、对话、输入和必要的来源/人工跟进入口；来源服务台等阻塞层打开时禁用桌宠。
- `prefers-reduced-motion` 下取消浮动、过渡与尾部动画，图片失败时保留文字触发器。

## 语气与验收

- 普通导览短句、温柔、略带潮汐意象，可使用少量项目创作性拟声词；不将俏皮表达用于政策或安全结论。
- 每种语言的离线回答、状态、来源和失败提示都必须有真实翻译，禁止非英中语言静默显示英文。
- 验收首页、ShellSong、Travel、Market、海南地图和六个展厅，在 `320/375/768/1115/1440px` 检查无溢出、可键盘操作、RTL 正常。
