# 模块引导：旅行页三段影像档案

## 目标

在 `#travel-atlas` 旅行图鉴中加入用户提供的文昌航天、东方非遗和美丽乡村三段视频，作为海南省文化出海主题下的项目影像阅读层。视频只丰富项目叙事，不改变路线编排、来源台、商城、六厅或螺音功能。

## 内容与资产边界

- 三段视频均作为项目提供的视觉/影像素材交付，文件名、版权归属和事实范围不在页面中扩展为官方证明。
- 文昌航天视频仅作为项目视觉语境；涉及当前航天信息时继续引导至已登记的 CNSA 官方来源。
- 东方非遗视频仅作为项目视觉语境；不据此证明具体传承人、产品、价格、开放状态或服务可得性。
- 美丽乡村视频仅作为项目视觉语境；不据此证明具体村落、路线、交通或现场条件。
- 不抓取外部视频、不新增第三方播放器、追踪 SDK、Cookie、摄像头、定位、对话或个人数据存储。
- 原始视频不覆盖；复制到 `public/assets/travel/archive/` 后以稳定 ASCII 文件名交付。

## 交互与无障碍

- 视频段位于旅行图鉴的来源台之前，桌面端三列，窄屏单列，不产生横向滚动。
- 视频使用 `controls`、`playsInline`、`preload="metadata"`，不自动播放声音；用户主动播放后由浏览器控制音量和暂停。
- 每段视频提供七语标题、短说明、素材边界标签和可访问名称；加载失败显示七语静态失败提示，不伪造播放成功。
- `prefers-reduced-motion` 下不自动播放或循环，不增加额外动画；键盘可聚焦并使用原生视频控制。
- 阿拉伯语沿用根级 RTL，视频画面本身保持正常 LTR 展示。

## 验收

- 检查三段视频只在旅行页路由加载，首页和其他路由不请求新增媒体。
- 在 `320px`、`375px`、`768px`、`1115px`、`1440px` 检查视频、标题、控制条和桌宠不重叠、不溢出。
- 逐一切换七种语言，确认标题、说明、标签和失败状态不回退为未翻译的英中二分支。
- 执行 `npm run build`、`npm run check:i18n`、`npm run test:server`、`node --check server.mjs` 和 `git diff --check`。
