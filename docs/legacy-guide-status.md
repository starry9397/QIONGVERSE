# Legacy Module Guide Status

Historical module guides are retained as implementation evidence. Where an older guide says exactly four zones, excludes Wenchang Aerospace, or treats Dongfang as the project's sole geographic subject, that scope is superseded by `project-blueprint.md` and `module-guide-province-governance-api-25.md`.

Affected historical guides include `module-guide-commercial-leads-06.md`, `module-guide-luoyin-api-open-04.md`, and `module-guide-verified-knowledge-05.md`. Their security, accessibility, fallback, source, and data-minimization guidance remains valid unless it conflicts with the province-level blueprint.
