# 螺音自动导游模块实施说明

## 目标

让螺音 AI 数字人桌宠在六大沉浸式展厅中根据本地角色/相机姿态识别附近展项，并以可打断的桌宠气泡和可选语音提供导览。

## 不可变边界

- 不修改六个展厅的空间布局、轮盘、索引和返回逻辑。
- 不上传或保存原始相机坐标、移动轨迹、路线或用户画像。
- 只使用已登记的展项点位和来源边界；缺少核验资料时明确说明未知。
- 桌宠是自动导游主形态，现有 3D 螺音角色保持为独立可选能力。
- 自动请求可被跳过、暂停、取消；接口故障时保留本地文字导览。

## 触发规则

1. 浏览器内从 `luoyin-world-move` 读取姿态。
2. 角色/相机进入点位半径，并且相机朝向点位达到阈值时匹配。
3. 同一点位在离开半径前不重复触发；离开后重新进入才允许触发。
4. 新点位请求会取消旧请求，避免快速移动产生请求队列。
5. 详情弹层、完整聊天、展厅索引和切换展厅会暂停自动导览。

## API 与隐私

自动导览只发送 `cueId`、`zoneId`、语言和语音开关到 `/api/luoyin/auto-guide`。服务器拒绝未知点位和额外字段，按客户端限流；服务器不接收世界坐标。

## 降级

- GLM 不可用：返回登记在本地的多语言项目语境导览。
- TTS 不可用：保留文字，并按用户设置尝试浏览器语音。
- WebGL/角色不可用：自由相机仍可触发导览。

## 验收门槛

- 六厅均有点位；花梨厅雕刻物、乡村厅景观点可触发。
- 面向点位才触发，离开后可再次触发。
- 自动开关、跳过、暂停和语音失败均不阻塞浏览。
- 七种语言、Arabic RTL、键盘焦点和现有展厅交互无回归。
