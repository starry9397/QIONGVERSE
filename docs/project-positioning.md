# HAINAN QIONGVERSE Project Positioning

## Effective immediately

All future website modules must position **HAINAN QIONGVERSE / 琼境** as a Hainan Province cultural-tourism presentation and a careful orientation layer for Hainan Free Trade Port public information.

The primary narrative subject is **Hainan Province / 海南省**, not Dongfang City alone. Dongfang City may appear only as one concrete Hainan location when the module has relevant supplied assets or reviewed sources. It must not be presented as the sole subject of the complete website unless the user explicitly changes this positioning again.

## Writing and content rules

- English-first visitor copy should introduce Hainan Province before a city-level location.
- Chinese copy must mirror that hierarchy: 海南省 first, then an individual city or locality where relevant.
- Free Trade Port content remains a public-information orientation layer. It must not imply eligibility, official advice, a government endorsement, a commercial guarantee, or a partnership.
- Existing completed Dongfang-focused modules are preserved as historical project work. New modules should connect them to the province-level narrative rather than silently recasting unsupported local facts.
- When a new module needs province-level factual statements, use an authoritative reviewed source or mark the material as project-provided curatorial context.

## Implementation gate

Every future module guide must repeat this positioning under both **Module goal** and **Content boundaries**, then verify it during acceptance.
