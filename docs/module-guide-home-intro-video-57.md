Use project-local static media through `publicMedia()`. Open directly into an image-led viewing plane with no visible heading or descriptive copy. Retain only unobtrusive, real playback controls and a close action; make the timeline optional and hidden by default. Do not change the Hero, global navigation, map, five-hall wheel, route structure, desktop-pet behavior, server API, or source boundaries. Do not store viewing, audio, playback-rate, or progress data, and do not emit any remote request besides the static media fetch. On failure, show a clear localized recovery state.
